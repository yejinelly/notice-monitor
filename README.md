# Notice Monitor Agent 🔔

학과 게시판, 대학·단과대 공지사항, 외부기관의 사업·연구비 공고 등 여러 채널에서 관심 키워드가 포함된 **새 글만** 찾아 이메일로 알려주는 공지 모니터링 서비스입니다.

## 주요 기능

- Streamlit에서 이메일·공지 채널·키워드·알림 주기 등록
- RSS와 일반 HTML 공지 게시판 수집
- 사이트별 필수(`all`)·선택(`any`) 키워드 필터링
- 구독자별 이전 확인 기록을 바탕으로 새 공지만 판별
- 새 공지의 제목·날짜·원문 링크를 Gmail로 발송

## 웹에서 사용하기

배포된 Streamlit 앱 URL에 접속하면 설치 없이 사용할 수 있습니다. 이메일 주소, 공지 채널 주소, 키워드, 알림 주기를 입력해 구독을 등록하세요. 등록 전에는 공지 미리보기로 URL과 키워드가 잘 작동하는지 확인할 수 있습니다.

첫 정기 실행은 현재 매칭 공지를 기준 목록으로 저장하고, 다음 실행부터 새 공지만 이메일로 보냅니다.

## 로컬에서 직접 실행하기 (개발자용)

```bash
pip install -r requirements.txt
streamlit run app.py
```

`requirements.txt`는 앱을 GitHub/Streamlit Community Cloud에 배포하거나, 개발자가 로컬에서 실행할 때만 필요합니다. 웹앱 사용자는 설치할 필요가 없습니다.

## 서비스 실행 및 정기 알림

운영자는 [Google Cloud Console](https://console.cloud.google.com/)에서 Gmail API를 사용 설정하고, 서비스 발신 계정의 OAuth 인증 정보를 `credentials.json`으로 저장합니다. `.env.example`을 복사해 `.env`를 만든 뒤 인증 경로와 DB 경로를 설정하세요.

기존 정기 실행 환경에서 아래 명령을 실행하도록 등록하면 됩니다.

```bash
python runner.py
```

`runner.py`는 모든 활성 구독을 읽고, 주기에 맞는 공지만 확인한 뒤 사용자별로 새 공지를 묶어 발송합니다.

## 구현 방식

1. 사용자가 이메일, 공지 채널, 키워드, 주기를 등록한다.
2. 정기 실행기가 RSS 또는 웹 게시판에서 최신 공지를 수집한다.
3. 제목과 본문을 기준으로 관심 키워드에 맞는 공고를 선별한다.
4. 구독자별 이전 기록과 비교해 새로 등록된 공지만 판별한다.
5. 제목, 게시일, 출처 링크를 이메일로 안내한다.

`any` 키워드는 하나 이상 포함될 때, `all` 키워드는 모두 포함될 때 공지가 매칭됩니다. 일반 HTML 게시판은 사이트 구조에 따라 CSS 선택자를 설정해야 할 수 있습니다.

## 정기 실행

이 도구는 실행할 때만 공지를 확인합니다. macOS의 `launchd`, Windows 작업 스케줄러 또는 서버의 cron으로 `python runner.py`를 원하는 주기에 실행하세요. Streamlit 앱과 정기 실행기는 동일한 영속 DB를 사용해야 합니다.

## 보안

`.env`, Gmail OAuth 인증 파일, 토큰 파일, 구독 DB는 GitHub에 올리지 마세요. 이 저장소의 `.gitignore`는 해당 파일을 기본적으로 제외합니다. 공개 운영 전에는 이메일 인증과 구독 해지 기능을 추가하세요.
