# Notice Monitor Agent 🔔

장학금, 연구비, 사업 공고처럼 놓치기 쉬운 정보를 대신 확인해 주는 공지 알림 서비스입니다.

학과 게시판, 대학·단과대 공지사항, 외부기관 공고 중 관심 있는 채널을 등록하면, 관련된 **새 공지만** 이메일로 알려줍니다.

## 어떻게 작동하나요?

```text
공지 채널과 관심 키워드 등록
        ↓
정기적으로 새 공지 확인
        ↓
관심 키워드에 맞는 공지만 선택
        ↓
이미 안내한 공지는 제외
        ↓
새 공지의 제목·날짜·링크를 이메일로 발송
```

첫 확인에서는 현재 공지를 기준 목록으로 저장합니다. 그다음부터 새로 올라온 공지만 이메일로 받습니다.

## 사용자는 무엇을 하나요?

배포된 Streamlit 앱 URL에 접속해 아래 항목만 입력하면 됩니다.

- 알림을 받을 이메일 주소
- 추적할 공지 채널 이름과 URL
- 관심 키워드: 예) `장학, 대학원, 연구비, 공모`
- 알림 주기: 정기 실행마다 또는 하루 한 번

등록 전에는 화면에서 공지를 미리 확인해 URL과 키워드가 잘 작동하는지 볼 수 있습니다. 웹앱 사용자는 GitHub, Python, 별도 설치가 필요 없습니다.

## 지원하는 공지 채널

- RSS 공지
- 일반 웹 게시판

일반 웹 게시판은 사이트마다 구조가 달라, 일부 사이트는 제목과 링크 위치를 지정하는 추가 설정이 필요할 수 있습니다.

## 운영 방법

이 부분은 서비스를 운영하는 사람을 위한 안내입니다.

### 1. Streamlit 화면 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

### 2. 이메일 발신 계정 설정

Gmail API를 사용할 발신 계정의 OAuth 인증 정보를 준비합니다.

```bash
cp .env.example .env
```

`.env`에서 인증 파일과 구독 정보 DB 경로를 설정합니다. 인증 파일, 토큰, DB 파일은 GitHub에 올리지 않습니다.

### 3. 정기 실행

기존 정기 실행 환경에서 아래 명령을 실행하도록 등록합니다.

```bash
python runner.py
```

`runner.py`는 등록된 사용자별 설정을 읽고, 새 공지가 있을 때만 이메일을 보냅니다.

## 구현에 사용한 구성

- **Streamlit**: 공지 채널과 알림 조건을 등록하는 화면
- **SQLite**: 사용자별 설정과 이미 안내한 공지 기록 저장
- **RSS·웹 게시판 수집기**: 최신 공지 확인
- **Gmail API**: 새 공지 이메일 알림 발송

## 보안과 개인정보

이메일 주소는 공지 알림에만 사용합니다. `.env`, Gmail OAuth 인증 파일, 토큰 파일, 구독 DB는 저장소에 올리지 않도록 `.gitignore`에 등록되어 있습니다.

공개 운영 전에는 이메일 인증과 구독 해지 기능을 추가할 예정입니다.
